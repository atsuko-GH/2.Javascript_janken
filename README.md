（２）制作アプリの説明
・じゃんけんの勝負
・たたくorかぶるの勝負
・制限時間との勝負
の3つ全てをクリアしないと勝てないゲーム。　

（３）工夫した点・こだわった点
・条件分岐が複雑になるので、最初にワークフロー図を描き、処理内容を整理したうえでコードを書き始めた。
　（VSCに「Draw.io Integration」をインストールして描いた。）
・たたくorかぶるの選択の制限時間を1～2.5秒の中でランダムに設定されるようにし、ゲーム難易度を上げた。

（４）難しかった点・次回トライしたいこと（または機能）
・何をconstにし、何をletにするのか？
・共通処理として外に出しておくもの、特定の処理としてfunction内に入れておくべきものは？
という所で、ひたすら迷子になった。

（５）備考（感想、シェアしたいことなどなんでも）
if文で「同じ」を表現するために==を使うと授業では習ったが、Claudからは===に慣れろと言われた。どちらが一般的なのか、エンジニアの同僚複数人に聞いてみたところ「基本的にはコーディングルールに従うが、記載がない場合は===にするかな。等価性は厳密である方が安心」という意見が多かったので、私も===を使いました。
MDNにも===推奨的なことが書いてありました。
